Was ist Solana?

Solana und sein natives Asset SOL

Solana ist ein Blockchain-Netzwerk, das für Zahlungen, Token-Transfers, dezentrale Anwendungen und digitale Assets verwendet wird. Entwickler erstellen Anwendungen, auf die Benutzer über kompatible Wallets zugreifen. SOL ist das native Asset des Netzwerks: Es zahlt Transaktionsgebühren und kann zur Unterstützung des Netzwerkbetriebs eingesetzt werden.

Projekte können ihre eigenen Tokens auf Solana ausgeben, getrennt von SOL. Jeder Token hat eine Mint-Adresse, die den Vermögenswert identifiziert. Token-Seiten, Wallets und Market-Tools verwenden diese Adresse, um seine Informationen abzurufen, während einzelne Pool-Adressen die Märkte identifizieren, in denen er handelt.
