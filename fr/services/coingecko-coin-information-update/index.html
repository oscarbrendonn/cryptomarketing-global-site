Portée détaillée des services

Comment préparer une mise à jour des informations sur les pièces CoinGecko ?

Un profil actuel pour votre projet crypto

Votre profil CoinGecko doit expliquer le projet tel qu'il fonctionne aujourd'hui. Ce service prépare les mises à jour des descriptions, des informations de marque et des jetons lorsqu'un produit évolue, qu'une nouvelle identité est lancée ou que des détails plus anciens doivent être corrigés. Le travail commence par la page des ressources existantes et les modifications que le projet souhaite publier.

Nous identifions les champs concernés avant rédaction. Ceux-ci peuvent inclure le nom du projet, le symbole, le logo, le site Web, la documentation, les réseaux pris en charge ou les ressources du développeur. L'équipe peut demander une correction ciblée ou une mise à jour coordonnée du profil, le travail sélectionné étant expliqué dans la proposition.

Description du projet et identité de marque

Nous transformons les documents du projet actuel en une description claire du produit, de ses principales caractéristiques et du rôle du token. Le texte est organisé pour quelqu'un qui découvre le projet via CoinGecko. Les fonctionnalités publiées et les plans à venir sont décrits dans le contexte approprié afin que les lecteurs puissent comprendre l'offre actuelle.

Pour une nouvelle identité visuelle, la préparation rassemble le logo sélectionné, le nom officiel du projet et l'annonce pertinente. Nous les comparons avec le site Web et la documentation, aidant ainsi le profil mis à jour à présenter une marque cohérente. Le projet examine la description et les illustrations avant de les utiliser dans la demande.

Détails du jeton pour le bon réseau

Les modifications techniques sont examinées par rapport aux informations sur le réseau et les contrats fournies par le projet. Nous vérifions que les noms, destinations des explorateurs et adresses des contrats font référence au même bien. Les projets multi-réseaux identifient l'adresse pertinente pour chaque chaîne afin que les informations provenant des différents déploiements restent claires.

Une migration de contrat, un ajustement de catégorie ou un changement d'approvisionnement peuvent nécessiter son propre type de demande. Nous identifions ces tâches liées lors de la préparation et coordonnons le service approprié si nécessaire. Cela permet à l'équipe de mettre à jour un profil plus large tout en gardant chaque changement technique correctement identifié.

Préparation de la soumission CoinGecko

La mise à jour des informations est préparée pour la plateforme partenaires de CoinGecko. Nous organisons les réponses pertinentes sur le terrain, les liens vers les projets en cours, les illustrations et les annonces officielles dans une soumission que le représentant du projet peut examiner. Seules les sections nécessaires aux modifications demandées sont complétées.

Le représentant soumet via le compte officiel. Si CoinGecko demande des informations supplémentaires sur le projet, la marque ou des détails techniques, l'assistance convenue peut inclure la préparation de cette réponse.

Examiner le profil de projet révisé

Lorsque les modifications deviennent visibles, nous comparons la page publique avec la description, la marque et les détails du jeton demandés. Le projet reçoit un aperçu concis des modifications publiées et de tous les éléments restants nécessitant une attention particulière dans le cadre du travail convenu.

Les documents finaux du projet peuvent prendre en charge une communication cohérente sur le site Web, les canaux communautaires et d'autres profils d'actifs. Les mises à jour des informations CoinMarketCap peuvent être coordonnées séparément lorsque les deux pages doivent être révisées. Les modifications futures du produit ou de la marque peuvent s'appuyer sur la description actuelle au lieu de partir de documents obsolètes.
