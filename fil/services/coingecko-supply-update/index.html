Detalyadong lawak ng paglilingkod

Paano inihahanda ang isang CoinGecko token supply update?

Dalhin ang token page na napapanahon

Nagbabago ang supply ng token habang nabuo ang isang proyekto. Ang mga paglabas ng vesting, pagsunog ng token, bagong pagpapalabas o paglipat ng kontrata ay maaaring mag-iwan ng mga numero sa isang pampublikong pahina ng token sa likod ng kasalukuyang impormasyon ng proyekto. Inihahanda ng serbisyong ito ang pag-update ng supply para sa CoinGecko, simula sa partikular na asset at mga numero na nangangailangan ng pansin.

Tinutukoy ng pagsusuri ang pahina, network at kontrata, pagkatapos ay ikinukumpara ang mga ipinakitang numero sa pinakabagong tokenomics ng proyekto. Ang circulating, total at maximum na supply ay pinangangasiwaan bilang magkahiwalay na field. Ang resulta ay isang malinaw na paglalarawan ng hiniling na pagbabago at ang impormasyong kailangan para ipaliwanag ito.

Ayusin ang mga kontrata, wallet at vesting

Ibinibigay ng proyekto ang kontrata ng token nito, mga link ng explorer at kasalukuyang mga numero ng supply, kasama ang mga nauugnay na alokasyon ng wallet at mga iskedyul ng paglabas. Ang Treasury, koponan, reserba, naka-lock at naka-vested na mga pag-aari ay nilalagyan ng label ayon sa layunin. Para sa mga paso o bagong pagpapalabas, kasama sa paghahanda ang kaukulang impormasyon sa transaksyon o kontrata.

Para sa isang asset sa ilang network, tinutukoy ang bawat kontrata at ang tungkulin nito. Ang isang bridged na bersyon, isang inilipat na token at ang orihinal na asset ay nangangailangan ng malinaw na paliwanag ng kanilang relasyon. Nakakatulong ito na ipakita ang mga bilang ng supply nang tuluy-tuloy sa dokumentasyon ng proyekto at mga pampublikong pahina ng token.

Ihanda ang breakdown ng supply

Ipinapaliwanag ng sheet ng pagkalkula ang kasalukuyang mga halaga, ang mga iminungkahing halaga at ang dahilan para sa bawat pagbabago. Ang mga pinagbabatayan na balanse at pinagmumulan ng supply ay naitala para sa parehong petsa ng sanggunian. Ginagawa nitong mas madaling pag-usapan ang isang pag-unlock, isang paso o isang naitama na alokasyon nang hindi pinaghahalo ang mga numero mula sa iba't ibang mga sandali.

Kasama sa supply form ng CoinGecko ang mga field para sa nasunog at hindi na-minted na mga token at para sa mga naka-lock o naka-vested na mga wallet. Ang paghahanda ay tumutugma sa bawat pitaka sa network nito at ipinapaliwanag ang papel nito, kaya ang kabuuan at nagpapalipat-lipat na mga seksyon ng supply ay maaaring kumpletuhin kasama ang nauugnay na impormasyon ng proyekto.

Ihanda ang kahilingan sa platform

Para sa CoinGecko, inihahanda ang kahilingan sa pamamagitan ng proseso ng self-service nito gamit ang kategorya ng Token Supply. Ang napiling token, mga patlang ng supply at mga detalye ng pitaka ay sama-samang sinusuri. Kung ang isang network o kontrata ay nangangailangan din ng pag-update sa pahina ng token, ang pag-update ng impormasyon na iyon ay pinag-uugnay nang hiwalay.

Ang Crypto Marketing Global ay nag-aayos ng mga numero, naghahanda ng teksto ng aplikasyon at pinagsasama-sama ang mga nauugnay na file. Sinusuri ng proyekto ang huling impormasyon at ang awtorisadong kinatawan nito ay nagsusumite sa pamamagitan ng opisyal na proseso ng platform. Ang anumang mga follow-up na tanong ay maaaring masagot gamit ang parehong data ng proyekto at breakdown ng supply.

Panatilihing nakahanay ang impormasyon ng supply sa proyekto

Ang inihandang pakete ay naglalaman ng mga hiniling na numero, mga tala sa pagkalkula, mga sanggunian sa pitaka at mga materyales sa aplikasyon. Pagkatapos ng pagsusumite, ang status ng kahilingan at anumang karagdagang tanong ay gagabay sa susunod na hakbang. Kapag lumitaw ang mga pagbabago sa pahina ng token, maihahambing ang mga nai-publish na halaga sa hiniling na pag-update.

Maaaring humiling ng isa pang update ang pagpapalabas, pagsunog, o paglipat sa ibang pagkakataon. Ang pagpapanatili sa breakdown ng supply ay nagbibigay sa koponan ng isang kapaki-pakinabang na panimulang punto para sa gawaing iyon. Ang mga pagbabago sa paglalarawan ng proyekto, pagba-brand o mga link sa website ay maaaring isaayos sa pamamagitan ng hiwalay na impormasyon ng barya at mga serbisyo sa pag-update ng link.
