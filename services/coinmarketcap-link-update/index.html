Detailed service scope

How is a CoinMarketCap link update prepared?

Bring your CoinMarketCap links up to date

A website relaunch, a new community channel or a changed social handle should be reflected on the project’s CoinMarketCap listing. Our link update service brings the proposed replacements into one clear request, helping visitors find the current destinations behind your token profile.

We begin by identifying the exact asset page and the links displayed there. The project supplies its preferred replacements, including any pages that should be removed. This establishes a focused update for the existing listing and makes the intended changes easy to review.

Connect the listing with your official channels

Each destination is checked against the project’s website and public profiles. The review covers broken pages, unexpected redirects, old usernames and community invitations. For a multilingual website, the project can choose the main landing page that should receive visitors from CoinMarketCap.

When an account or domain has changed, a public announcement from an established project channel helps explain the transition. We bring those details together with the replacement URLs, giving the request the context needed to connect the new addresses to the listed asset.

Use the existing listing update route

CoinMarketCap’s request form provides an information update option for an existing cryptoasset, including URL changes. We prepare the relevant form responses and a compact before-and-after list so the requested website, social or documentation updates are clearly identified.

Broader changes such as a new token identity, contract swap or supply revision are identified separately during preparation.

Prepare the project’s submission

The final request combines the asset page, replacement links and a short explanation of the changes. The project representative reviews these materials and submits them through the official CoinMarketCap route. We provide the preparation support agreed for that submission.

If the platform replies with a question about a destination or the project’s connection to it, the follow-up addresses that question directly. Relevant announcements and current website information are used to prepare a clear response without rebuilding the entire request from the beginning.

Check the public page after the change

After the listing is updated, the published addresses are compared with the supplied replacements. We open the affected links and confirm where they lead, including any redirects. The project receives a concise overview of the changes visible on its CoinMarketCap page.

Keeping a current set of official URLs also makes future campaigns easier to organise. The same destinations can be used in project announcements and other listing updates. CoinGecko link maintenance is available as a separate service when both profiles need attention.
