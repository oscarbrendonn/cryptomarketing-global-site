Detailed service scope

How is a CoinGecko link update prepared?

Keep your token page connected to your project

An updated CoinGecko page helps people move from token research to your official website and community. This service prepares changes to website, whitepaper, social profile, explorer and repository links when a project launches a new site, changes a handle or replaces an old destination.

The starting point is your existing token page and a list of the links to add, replace or remove. Each proposed destination is matched to the correct project and network. A simple website change can be handled as a focused request, with the rest of the listing retained.

Check the new destinations

We review whether the supplied URLs open correctly and lead to the intended page. Website redirects, outdated whitepaper files, changed X handles and expired community invitations are checked together so the updated listing directs visitors to resources that the project actually uses.

If the website has moved to a new domain, the preparation includes the announcement explaining that move. Links published by the project help establish continuity between the existing listing and the replacement destinations. The team confirms which addresses should appear before the request is prepared.

Prepare the CoinGecko update

CoinGecko accepts existing project information updates through its Partners Platform. We organise the requested changes for the relevant sections, such as website and whitepaper details, community links or developer resources, and prepare a concise explanation for the submission.

The completed materials show each current link alongside its replacement and include the project announcements relevant to the change. A contract migration or a wider rebrand can be coordinated with the corresponding information update service when those changes are also needed.

Coordinate submission and follow-up

The project representative receives the prepared answers and supporting links for submission through the official account. The service can include help with questions about the submitted URLs, keeping the response consistent with the new website and community pages.

Once a request has been submitted, its status can be checked in the Partners Platform. If CoinGecko asks for clarification, we help organise the specific additional information requested.

Review the updated links

When the changes appear, we compare the public token page with the requested destinations and check that the links open correctly. This final review focuses on the website, documents and profiles covered by the order, giving the project a clear view of the completed changes.

The resulting link list can also support updates on other project channels. If CoinMarketCap still points to an older website or profile, its separate link update service can be included in the same campaign plan so visitors find consistent official information.
