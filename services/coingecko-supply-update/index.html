Detailed service scope

How is a CoinGecko token supply update prepared?

Bring the token page up to date

Token supply changes as a project develops. Vesting releases, token burns, new issuance or a contract migration can leave the figures on a public token page behind the project’s current information. This service prepares the supply update for CoinGecko, starting with the specific asset and the figures that need attention.

The review identifies the page, network and contract, then compares the displayed figures with the project’s latest tokenomics. Circulating, total and maximum supply are handled as separate fields. The result is a clear description of the requested change and the information needed to explain it.

Organize contracts, wallets and vesting

The project provides its token contract, explorer links and current supply figures, together with relevant wallet allocations and release schedules. Treasury, team, reserve, locked and vested holdings are labeled by purpose. For burns or new issuance, the preparation includes the corresponding transaction or contract information.

For an asset on several networks, each contract and its role are identified. A bridged version, a migrated token and the original asset need a clear explanation of their relationship. This helps present the supply figures consistently across the project’s documentation and public token pages.

Prepare the supply breakdown

The calculation sheet explains the current values, the proposed values and the reason for each change. The underlying balances and supply sources are recorded for the same reference date. This makes it easier to discuss an unlock, a burn or a corrected allocation without mixing figures from different moments.

CoinGecko’s supply form includes fields for burned and unminted tokens and for locked or vested wallets. The preparation matches each wallet to its network and explains its role, so the total and circulating supply sections can be completed with the relevant project information.

Prepare the platform request

For CoinGecko, the request is prepared through its self-service process using the Token Supply category. The selected token, supply fields and wallet details are checked together. If a network or contract also needs updating on the token page, that information update is coordinated separately.

Crypto Marketing Global organizes the figures, prepares the application text and brings the relevant files together. The project reviews the final information and its authorized representative submits through the platform’s official process. Any follow-up questions can then be answered using the same project data and supply breakdown.

Keep supply information aligned with the project

The prepared package contains the requested figures, calculation notes, wallet references and application materials. After submission, the request status and any additional questions guide the next step. Once changes appear on the token page, the published values can be compared with the requested update.

A later vesting release, burn or migration may call for another update. Retaining the supply breakdown gives the team a useful starting point for that work. Changes to the project’s description, branding or website links can be arranged through the separate coin information and link update services.
