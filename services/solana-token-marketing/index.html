What is Solana?

Solana and its native asset SOL

Solana is a blockchain network used for payments, token transfers, decentralized applications and digital assets. Developers build applications that users access through compatible wallets.

Projects can issue their own tokens on Solana, separate from SOL. Each token has a mint address that identifies the asset. Token pages, wallets and market tools use that address to retrieve its information, while individual pool addresses identify the markets in which it trades.
