Detailed service scope

How is a CoinMarketCap token supply update prepared?

Bring the token page up to date

This service prepares changes to the supply figures on an existing CoinMarketCap asset page. It is useful when the project has released previously locked tokens, changed its issuance, completed a burn or found a difference between the page and its current tokenomics.

The first deliverable is an update table showing which figures need attention. It identifies the current published value, the replacement requested by the project and the reason for that replacement. The team can then review the proposed changes together before the application is prepared.

Organize contracts, wallets and vesting

Preparation starts with the canonical contract, supported network and explorer page. The token name, symbol and decimals are checked against the asset being updated. For a migration, the materials explain the old and new contracts and which supply figures belong to each.

The wallet breakdown describes how the project’s supply is allocated. Team holdings, treasury balances, locked amounts and release schedules are presented with their relevant addresses. This gives the application a clear connection between the tokenomics description and the balances used to prepare the requested figures.

Prepare the supply breakdown

Amounts are presented in token units with an identified reference date. A rounded figure from a presentation can be expanded into the underlying value for the update. Circulating, total and maximum supply each receive their own explanation so the form answers remain consistent.

CoinMarketCap reviews circulating, total and maximum supply under its own supply methodology. The preparation explains holdings allocated to the team, treasury and other relevant groups, together with locked balances and release schedules. Each amount is connected to the project information used in the calculation.

Prepare the platform request

For CoinMarketCap, the request is prepared for the existing cryptoasset supply update form. The token page and requested supply figures are matched to the project’s contracts and supporting materials. This keeps an update to an existing asset distinct from a new asset listing request.

The work produces an application-ready set of numbers and explanations for the project representative. Crypto Marketing Global prepares the text and the accompanying calculation materials. The representative confirms the final figures and uses the official CoinMarketCap form to submit the update for the existing asset.

Keep supply information aligned with the project

Follow-up work can address a question about a wallet, a release date or a supply source. The relevant section of the calculation is updated as needed. When new values become visible, the team checks the asset page against the specific fields included in the request.

The completed materials remain useful for the project’s next supply change. A new release schedule or contract version can be added to the existing breakdown. If the same project also needs CoinMarketCap website links, branding or descriptive information updated, those tasks can be coordinated through their dedicated services.
