Detailed service scope

How is a CoinGecko coin information update prepared?

A current profile for your crypto project

Your CoinGecko profile should explain the project as it operates today. This service prepares updates to descriptions, branding and token information when a product evolves, a new identity launches or older details need correction. The work starts with the existing asset page and the changes the project wants to publish.

We identify the affected fields before drafting. These may include the project name, symbol, logo, website, documentation, supported networks or developer resources. The team can request one focused correction or a coordinated profile update, with the selected work explained in the proposal.

Project description and brand identity

We turn current project materials into a clear description of the product, its main features and the token’s role. The text is organised for someone discovering the project through CoinGecko. Published features and upcoming plans are described in the appropriate context so readers can understand the current offering.

For a new visual identity, the preparation brings together the selected logo, official project name and relevant announcement. We compare these with the website and documentation, helping the updated profile present one coherent brand. The project reviews the description and artwork before they are used in the request.

Token details for the right network

Technical changes are reviewed against the network and contract information supplied by the project. We check that names, explorer destinations and contract addresses refer to the same asset. Multi-network projects identify the relevant address for each chain so information from different deployments is kept clear.

A contract migration, category adjustment or supply change may require its own request type. We identify those connected tasks during preparation and coordinate the appropriate service where needed. This lets the team update a broader profile while keeping each technical change properly identified.

CoinGecko submission preparation

The information update is prepared for CoinGecko’s Partners Platform. We organise the relevant field answers, current project links, artwork and official announcements into a submission the project representative can review. Only the sections needed for the requested changes are completed.

The representative submits through the official account. If CoinGecko asks for additional context about the project, brand or technical details, the agreed support can include preparing that response.

Review the revised project profile

When the changes become visible, we compare the public page with the requested description, branding and token details. The project receives a concise overview of the published changes and any remaining items that need attention within the agreed work.

The final project materials can support consistent communication across the website, community channels and other asset profiles. CoinMarketCap information updates can be coordinated separately when both pages need revision. Future product or brand changes can build on the current description instead of starting from outdated material.
