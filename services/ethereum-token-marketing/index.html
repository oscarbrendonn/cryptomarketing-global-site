What is Ethereum?

Ethereum, ETH and the ERC20 standard

Ethereum is a blockchain network that runs smart contracts: programs used to build decentralized applications and digital assets. Users interact with Ethereum applications through compatible wallets.

ERC20, also written ERC-20, is a common standard for fungible tokens implemented by smart contracts. It defines functions such as balances, transfers and spending approvals so wallets and applications can work with compatible tokens. An ERC20 token has its own contract address and is distinct from Ethereum’s native ETH.
