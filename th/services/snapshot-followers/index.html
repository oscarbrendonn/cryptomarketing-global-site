Snapshot คืออะไร?

การสนับสนุนแคมเปญผู้ติดตาม Snapshot ครอบคลุมอะไรบ้าง

Snapshot มอบพื้นที่การกำกับดูแลนอกเครือข่ายที่ชุมชนสามารถเผยแพร่ข้อเสนอและกลยุทธ์การลงคะแนนได้ ผู้ติดตามคือความสัมพันธ์ที่มองเห็นได้ในพื้นที่หนึ่งๆ แต่พวกเขาไม่ใช่อำนาจในการลงคะแนน บริการนี้ครอบคลุมเฉพาะรายการผู้ติดตามและไม่ได้กำหนดค่ากลยุทธ์ มอบหมายกระเป๋าเงิน หรือมีอิทธิพลต่อผลลัพธ์ของข้อเสนอ

แยกการจัดส่งผู้ติดตามออกจากอำนาจการลงคะแนน สิทธิ์กระเป๋าสตางค์ การเข้าร่วมข้อเสนอ และผลลัพธ์การกำกับดูแล สำหรับการสนับสนุนแคมเปญผู้ติดตาม Snapshot ชื่อย่อที่ลงนามแล้วจะตั้งชื่อการส่งมอบที่ควบคุมได้และปลายทางแยกจากกัน ซึ่งจะทำให้ป้ายกำกับบริการไม่ถูกเข้าใจผิดเกี่ยวกับการอนุมัติ Snapshot การอ้างสิทธิ์อัลกอริทึม หรือการคาดการณ์เกี่ยวกับพฤติกรรมของผู้ใช้

ขอบเขตสำหรับ Snapshot

ระบุ URL พื้นที่ Snapshot บริบทเครือข่ายที่เกี่ยวข้อง การแสดงผู้ติดตามปัจจุบัน ปริมาณและเวลาที่ร้องขอ งานจัดเตรียมพื้นที่ การเขียนข้อเสนอ และงานกลยุทธ์การลงคะแนนเสียงเป็นงานทางเทคนิคที่แยกจากกัน และไม่ได้อนุมานจากคำสั่งของผู้ติดตาม

การนำส่งของผู้ติดตาม Snapshot สำหรับ URL ของพื้นที่ ปริมาณ และกรอบเวลาการนำส่งที่ยืนยันแล้ว การสนับสนุนแคมเปญของผู้ติดตาม Snapshot ประกอบด้วยการค้นพบ การกำหนดขอบเขต การวางแผนผู้ชมและข้อความ การเตรียมเนื้อหาที่ได้รับอนุมัติ การประสานงานของช่อง บันทึกการตีพิมพ์ การตั้งค่าการระบุแหล่งที่มา และการสรุปที่มีหลักฐานเป็นหลักฐาน

อินพุต การจัดส่ง และแฮนด์ออฟ

บันทึกความสมบูรณ์ชี้ไปที่ช่องว่าง Snapshot ที่แน่นอน และระบุหน่วยที่ร้องขอและสถานะที่สังเกตได้ มันไม่ได้แสดงรายการผู้ติดตามว่าเป็นผู้มีสิทธิ์ลงคะแนนเสียงหรือผู้ถือโทเค็น การเข้าร่วมข้อเสนอและอำนาจการลงคะแนนจำเป็นต้องมี Snapshot ของตนเองหรือหลักฐานออนไลน์ และถูกแยกออกจากการรายงานของผู้ติดตาม

การสนับสนุนแคมเปญผู้ติดตาม Snapshot เริ่มต้นหลังจากขอบเขต เวลา และความพร้อมที่ตรงกับบรีฟที่เขียนไว้เท่านั้น ก่อนที่เราจะเริ่ม เราจะจดบันทึกสิ่งที่เราจะทำ สิทธิ์การเข้าถึงใดที่เราต้องการ และระยะเวลาเท่าใด ในตอนท้ายคุณจะได้รับการส่งมอบสั้นๆ: สิ่งที่ทำเสร็จแล้ว ไฟล์ที่ได้รับอนุมัติ และทุกสิ่งที่ขึ้นอยู่กับบุคคลที่สาม คุณยังรู้ด้วยว่าใครเป็นผู้รับผิดชอบ คุณจะได้รับหลักฐานอะไร และเราเช็คอินกับคุณเมื่อใด
