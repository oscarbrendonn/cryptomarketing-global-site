Batafsil xizmat ko'rsatish doirasi

Base token kampaniyasini nima o'ziga xos qiladi?

Base bu Ethereum virtual mashinasi bilan mos keladigan Ethereum Layer 2 tarmog‘idir. ETH tranzaksiya to‘lovlarini Base da to‘laydi va loyihalar ERC20 standarti yordamida tokenlarni chiqarishi mumkin. ERC20 yorlig'i token standartini aniqlaydi; Base tarmog'i va shartnoma manzili targ'ib qilinayotgan joylashtirishni aniqlaydi.

Ushbu farq kampaniya havolasi, token profili yoki hamjamiyat e'lonini tayyorlashda muhim ahamiyatga ega. Belgilangan manzilni tanlashdan oldin shartnoma va savdo juftligi Base ga tegishli ekanligini tasdiqlang. Ethereum asosiy tarmoq sahifasi, boshqa joylashtirish yoki shunga o'xshash belgi bu token uchun mo'ljallangan trafikni qabul qilmasligi kerak.
