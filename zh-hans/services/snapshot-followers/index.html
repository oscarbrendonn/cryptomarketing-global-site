详细服务范围

什么是 Snapshot？

Snapshot 关注者活动支持涵盖哪些内容

Snapshot 提供链下治理空间，社区可以在其中发布提案和投票策略。追随者是与空间的可见关系，但他们不具有投票权。该服务仅涵盖关注者项目，不配置策略、委托钱包或影响提案结果。

将追随者交付与投票权、钱包资格、提案参与和治理结果分开。对于 Snapshot 关注者活动支持，签署的简报分别命名可控交付物和目的地。这可以防止服务标签被误认为是 Snapshot 批准、算法声明或有关用户行为的预测。

Snapshot 的范围

提供 Snapshot 空间 URL、相关网络上下文、当前关注者显示、请求数量和时间。空间设置、提案撰写和投票策略工作是独立的技术任务，不能从关注者订单中推断出来。

Snapshot 关注者交付已确认的空间 URL、数量和交付窗口。 Snapshot 关注者活动支持包括发现、范围定义、受众和消息规划、批准的内容准备、渠道协调、发布记录、归因设置和以证据为主导的摘要。

输入、交付和移交

完成记录指向确切的 Snapshot 空间并说明请求的单元和观察到的状态。它不会将追随者列为合格选民或代币持有者。提案参与和投票权需要自己的 Snapshot 或链上证据，并且不包括在关注者报告中。

Snapshot 追随者活动支持仅在范围、时间和可用性与书面简介相符后开始。在开始之前，我们写下我们要做什么、需要哪些访问权限以及需要多长时间。最后，您会收到一份简短的移交信息：已完成的工作、已批准的文件以及依赖于第三方的任何内容。您还知道谁负责、您将获得什么证据以及我们何时与您联系。
