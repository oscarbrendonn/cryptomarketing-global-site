详细服务范围

为什么 Gate Alpha 的可见性很重要

Gate Alpha 是 Gate 的链上角落：Gate 用户无需离开账户即可浏览新兴代币并进行交易。专门来这里寻找新东西的人会看到在其发现区域中出现的令牌。

热门活动将这一时刻变成了一个计划好的窗口，而不是一个幸运的窗口。我们围绕您的代币名称、股票代码和合约构建它，因此交易者在 Gate Alpha 中看到的内容与您的网站、社交媒体和列表相匹配。

活动如何进行

首先我们检查您的 Gate Alpha 代币页面、合约和官方链接。然后我们与您商定活动窗口并协调该时期的趋势活动。当它运行时，我们会观察令牌的位置并向您发送简短的更新。

许多团队将活动与 Gate Alpha 列表或社区公告配对。这样，当您自己的渠道处于活动状态时，注意力窗口就会准确打开，并且这两种努力会相互支持而不是相互竞争。

我们需要您做什么

将您的 Gate Alpha 代币页面的链接、股票代码、网络和合约地址发送给我们。添加官方网站、您的社交帐户以及您想要的活动日期。

如果有发布、空投或合作伙伴公告即将发布，请告诉我们。与您的新闻同一天发布的营销活动通常会从它所引起的关注中获得更多。
