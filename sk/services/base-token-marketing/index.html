Čo robí kampaň Base token špecifický?

Base je Ethereum Vrstva 2 sieť kompatibilná s Ethereum Virtual Machine. ETH platí transakčné poplatky za Base, a projekty môžu vydávať žetóny s použitím normy ERC20. Base v prípade siete a zmluvnej adresy sa identifikuje podporovaná rozmiestnenie.

Tento rozdiel záleží pri príprave kampane odkaz, symbolický profil alebo komunitné oznámenie. Potvrdiť, že zmluva a obchodovanie pár patrí Base Pred výberom miesta určenia. An Ethereum stránka mainnet, iné nasadenie alebo podobné zariadenie by nemali dostávať prevádzku určenú pre tento token.
