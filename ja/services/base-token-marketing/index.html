詳しいサービス範囲

Base トークン キャンペーンの特徴は何ですか?

Base は、Ethereum 仮想マシンと互換性のある Ethereum レイヤ 2 ネットワークです。 ETH は Base で取引手数料を支払い、プロジェクトは ERC20 標準を使用してトークンを発行できます。 ERC20 ラベルはトークン標準を識別します。 Base ネットワークと契約アドレスは、推進されている展開を識別します。

この区別は、キャンペーン リンク、トークン プロファイル、またはコミュニティの発表を準備するときに重要です。宛先を選択する前に、契約と取引ペアが Base に属していることを確認してください。 Ethereum メインネット ページ、別のデプロイメント、または同様のティッカーは、このトークンを対象としたトラフィックを受信すべきではありません。

発見と有用なプロジェクト情報を結びつける

視聴者が実際に訪問するサーフェス、つまり、Base 取引ペア、サポートされているトークン プロファイル、またはプロジェクト コミュニティから始めます。関連する DEX 可視化サービス、アプリケーションと投票パッケージのリストを選択し、それらの配置を明確なプロジェクト情報と一貫した公式リンクに接続します。

コミュニティの投稿、地域のプロモーション、PR、KOL コンテンツによって、さまざまな視聴者にトークンについて説明できます。 CertiK ウォッチリストのサポートは、該当する場合、その特定の機能に関係するものであり、セキュリティ監査に代わるものではありません。リストリクエスト、投票パッケージ、トレンドパッケージにはそれぞれ独自のスコープがあります。

Baseの契約とキャンペーン先の準備

Base 契約アドレス、トークン名とシンボル、公式 Web サイト、ソーシャル プロフィール、および正確なペアまたはリスト URL を送信します。プロジェクトの段階、対象言語、対象読者を含めます。複数のプールが存在する場合は、キャンペーンの注目を集めるプールを特定します。

新たにリリースする場合は、どの公開ページがすでに利用可能で、どのアプリケーションが未完成のままであるかを記載します。確立されたトークンについては、現在のプロファイルの詳細と必要な修正を共有します。当社では、すべてのカタログ項目を自動的に適用できるものとして扱うのではなく、サービスをプロジェクトに適合させるためにこれらの資料を使用します。

作業に同意し、選択した目的地に従います

以下の関連サービスを選択し、キャンペーンの提案をリクエストしてください。提案書では、目的地、成果物、各項目に必要な情報が特定されます。

起動前に、承認されたコピーが正しいネットワーク名、契約、およびコミュニティ リンクを使用していることを確認してください。合意された宛先に対して配信されたプレースメントを確認します。プラットフォームの受け入れ、ランキング、視聴者の反応、トークンのパフォーマンスは、提供された作品とは切り離されたままであるため、キャンペーン計画では成果物を明確に説明する必要があります。
