詳しいサービス範囲

CoinGecko リンク更新はどのように準備されますか?

トークン ページをプロジェクトに接続したままにします

更新された CoinGecko ページは、人々がトークン調査から公式 Web サイトやコミュニティに移動するのに役立ちます。このサービスは、プロジェクトが新しいサイトを立ち上げたり、ハンドルを変更したり、古い宛先を置き換えたりするときに、Web サイト、ホワイトペーパー、ソーシャル プロファイル、エクスプローラー、リポジトリ リンクへの変更を準備します。

開始点は、既存のトークン ページと、追加、置換、または削除するリンクのリストです。提案された各宛先は、正しいプロジェクトとネットワークに適合します。単純な Web サイトの変更は、リストの残りの部分を保持したまま、集中的なリクエストとして処理できます。

新しい目的地を確認する

提供された URL が正しく開き、目的のページにアクセスできるかどうかを確認します。 Web サイトのリダイレクト、古いホワイトペーパー ファイル、変更された X ハンドル、および期限切れのコミュニティへの招待がまとめてチェックされるため、更新されたリストによって訪問者はプロジェクトが実際に使用するリソースに誘導されます。

Web サイトが新しいドメインに移動した場合、準備にはその移動を説明するアナウンスが含まれます。プロジェクトによって公開されたリンクは、既存のリストと置換先の間の連続性を確立するのに役立ちます。チームは、リクエストを準備する前に、どのアドレスを表示する必要があるかを確認します。

CoinGecko アップデートの準備

CoinGecko は、パートナー プラットフォームを通じて既存のプロジェクト情報の更新を受け入れます。 Web サイトやホワイトペーパーの詳細、コミュニティ リンク、開発者リソースなど、関連するセクションに対して要求された変更を整理し、提出用の簡潔な説明を準備します。

完成した資料には、現在の各リンクとその置き換えが表示され、変更に関連するプロジェクトの発表も含まれています。契約の移行や広範なブランド変更も必要な場合は、対応する情報更新サービスと調整できます。

提出とフォローアップの調整

プロジェクトの代表者は、公式アカウントを通じて、準備された回答と提出用のサポート リンクを受け取ります。このサービスには、送信された URL に関する質問に対するヘルプが含まれており、新しい Web サイトやコミュニティ ページとの応答の一貫性を保つことができます。

リクエストが送信されると、そのステータスはパートナー プラットフォームで確認できます。 CoinGecko が説明を求めた場合は、要求された特定の追加情報の整理をお手伝いします。

更新されたリンクを確認する

変更が表示されると、パブリック トークン ページと要求された宛先を比較し、リンクが正しく開くことを確認します。この最終レビューでは、注文の対象となる Web サイト、ドキュメント、プロファイルに焦点を当て、プロジェクトに完了した変更を明確に把握できるようにします。

結果として得られるリンク リストは、他のプロジェクト チャネルの更新もサポートできます。 CoinMarketCap がまだ古い Web サイトまたはプロフィールを指している場合は、その別のリンク更新サービスを同じキャンペーン プランに含めることができるため、訪問者は一貫した公式情報を見つけることができます。
