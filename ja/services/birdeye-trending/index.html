詳しいサービス範囲

Birdeyeとは何ですか？

Birdeye は、Solana を含む複数のブロックチェーンにわたるトークンを追跡する暗号市場データおよび分析プラットフォームです。

ユーザーはトークンを検索し、活発な市場を探索し、価格の動きとともにウォレットやトレーダーの活動を調べることができます。 Birdeye はデータ API も提供しており、開発者がトークン、ペア、ウォレットの情報を独自のアプリケーションや調査ツールに取り込むことができます。

Birdeye のトレンドは何ですか?

Birdeye トレンドは、トレーダーがオンチェーン資産と取引ペアを探索する場所でトークンを宣伝します。プロモーション期間中の可視性をサポートするスクリプトとカスタム キャンペーン ツールを使用して、選択した Birdeye トークン ページを中心にキャンペーンを実行します。

Birdeye キャンペーンは、トークンの発売、プロジェクトの発表、または継続的な可視性の推進に伴う場合があります。私たちは、選択されたトークン ページのスクリプトを準備し、プロジェクト ページをプロモーションの中心に据えながら、予約された期間にわたってキャンペーンを管理します。

Birdeyeの範囲

概要には、Birdeye URL、ネットワーク、契約アドレス、ペアの選択、要求されたキャンペーン期間、およびプロジェクトの望ましい完了証拠が必要です。引用する前に、ページが目的のアセットに解決され、要求されたサーフェスがまだ利用可能である必要があります。別のペアまたはチェーンは別の宛先として扱われます。

Birdeye トレンドサポート: お問い合わせください。 Birdeye トレンド サポートには、ディスカバリー、スコープ定義、視聴者とメッセージの計画、承認されたコンテンツの準備、チャネル調整、出版記録、帰属設定、および証拠に基づく概要が含まれます。

入力、配信、およびハンドオフ

配信記録は、合意された URL、開始コンテキスト、作業ウィンドウ、および完了時に観察可能な結果を識別します。 Birdeye インターフェイスがパーソナライズされた場合、またはキャンペーン中に変更された場合、レポートでは、別の画面を置き換えるのではなく、その制限が記載されます。証拠は、選択したペアとタイムスタンプに固有に保持されます。

Birdeye トレンド サポートは、範囲、タイミング、可用性が概要書面と一致した場合にのみ開始されます。始める前に、何をするのか、どのアクセスが必要なのか、どのくらいの期間必要なのかを書き留めます。最後に、何が行われたか、承認されたファイル、およびサードパーティに依存するものすべてを含む短い引き継ぎを受け取ります。また、誰が責任を負うのか、どのような証拠が得られるのか、いつ確認されるのかもわかります。
