詳しいサービス範囲

CoinGecko コイン情報の更新はどのように準備されますか?

暗号化プロジェクトの現在のプロファイル

CoinGecko プロフィールでは、現在運営されているプロジェクトについて説明する必要があります。このサービスは、製品が進化したとき、新しい ID が発売されたとき、または古い詳細の修正が必要になったときに、説明、ブランド、トークン情報の更新を準備します。作業は既存のアセット ページと、プロジェクトが公開したい変更から始まります。

ドラフト前に影響を受けるフィールドを特定します。これらには、プロジェクト名、シンボル、ロゴ、Web サイト、ドキュメント、サポートされているネットワーク、または開発者リソースが含まれる場合があります。チームは、提案書で説明されている選択された作業とともに、1 つの集中的な修正または調整されたプロファイルの更新をリクエストできます。

プロジェクトの説明とブランドアイデンティティ

現在のプロジェクト資料を、製品、その主な機能、トークンの役割の明確な説明に変換します。このテキストは、CoinGecko を通じてプロジェクトを発見した人向けに構成されています。公開された機能と今後の計画は、読者が現在のサービスを理解できるように、適切なコンテキストで説明されています。

新しいビジュアル アイデンティティを作成するために、選択したロゴ、公式プロジェクト名、関連する発表をまとめて準備します。これらを Web サイトやドキュメントと比較し、更新されたプロファイルで 1 つの一貫したブランドを提示できるようにします。プロジェクトは、リクエストで使用される前に説明とアートワークをレビューします。

適切なネットワークのトークンの詳細

技術的な変更は、プロジェクトによって提供されたネットワークおよび契約情報に照らしてレビューされます。名前、エクスプローラーの宛先、およびコントラクトのアドレスが同じアセットを参照していることを確認します。マルチネットワーク プロジェクトでは、各チェーンに関連するアドレスが識別されるため、さまざまな展開からの情報が明確に保たれます。

契約の移行、カテゴリの調整、または供給の変更には、独自のリクエスト タイプが必要になる場合があります。私たちは準備中に関連するタスクを特定し、必要に応じて適切なサービスを調整します。これにより、チームは各技術的な変更を適切に識別しながら、より広範なプロファイルを更新できるようになります。

CoinGecko提出準備

情報の更新は、CoinGecko のパートナー プラットフォーム用に準備されています。関連するフィールドの回答、現在のプロジェクトのリンク、アートワーク、公式発表を、プロジェクトの代表者が確認できる提出物にまとめます。要求された変更に必要なセクションのみが完了します。

代表者が公式アカウントより提出します。 CoinGecko がプロジェクト、ブランド、または技術的な詳細に関する追加のコンテキストを要求した場合、合意されたサポートにはその応答の準備が含まれる場合があります。

改訂されたプロジェクト プロファイルを確認する

変更が表示されると、公開ページと要求された説明、ブランド、トークンの詳細を比較します。プロジェクトは、公開された変更と、合意された作業内で注意が必要な残りの項目の簡潔な概要を受け取ります。

最終的なプロジェクト資料は、Web サイト、コミュニティ チャネル、その他の資産プロファイル全体にわたる一貫したコミュニケーションをサポートできます。 CoinMarketCap 情報の更新は、両方のページの改訂が必要な場合に個別に調整できます。将来の製品やブランドの変更は、古い資料から始めるのではなく、現在の説明に基づいて行うことができます。
