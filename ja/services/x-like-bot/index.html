XとTelegramエンゲージメントワークフロー

TelegramコミュニティとXキャンペーンリンクを接続します。投稿された投稿、モデレータレビュー、キャンペーンメッセージ、アクティビティを1つのワークフローで管理します。

  • X 認証エンゲージメントワークフロー

    X および Telegram キャンペーンワークフローでは、アカウントの接続、モデレータのアクション、スケジューリング、インターフェイスの機能について説明します。

詳しいサービス範囲

X と Telegram 間での承認されたエンゲージメントアクションはどのように調整されますか?

TelegramキャンペーンでX投稿を接続

このワークフローは、XキャンペーンリンクをTelegramグループに展開します。モデレータは、送信された投稿を収集し、メッセージを確認し、コミュニティと共有するときに選択することができます。キャンペーンリンクと出版物タスクは、管理可能なキューにまとめられます。

接続されたアカウント、Telegramグループとモデレータのアクションは、キャンペーンの要件のために構成されます。パネルは、送信されたリンク、スケジュールされたメッセージ、および完了した手順を表示することができます。モデレータは、公開を制御しますが、アクティビティは、レビューされた投稿を識別したり、コミュニティと共有したりします。

開発とサービス範囲

選択したXアカウント、Telegramグループとモデレータワークフローは、開発要件を定義します。利用可能な機能は、レビューキュー、スケジュールされたメッセージ、管理パネルが含まれます。

サンプルキャンペーン投稿とTelegramグループの要件は、評価をサポートしています。 提案は、ワークフロー開発、インストール、サポートを仕様しています。

入力、配信、およびハンドオフ

テストは、リンクの取入口、許可チェック、拒否された入力、レート・リミット処理、および指定されたアカウントで承認されたアクション・パスを実証します。 Handoff には、設定と無効な手順が含まれます。 ログはワークフローイベントのみを表示します。 それらは、オーガニック・エピメントまたは独立したコミュニティ・レスポンスとして記述されていません。

XとTelegramエンゲージメントワークフローは、スコープ、タイミング、および可用性が書かれた簡潔に一致した後にのみ始まります。 開始する前に、私たちが何をすべきかを書き留めます。 必要なアクセスとどのくらいの期間。 最後に、あなたは短い取引を受け取ります。 何をやったか、承認されたファイル、およびサードパーティに依存するもの。 また、あなたは誰が責任を負っているか、あなたが受け取る証拠、そして私たちはあなたにチェックインするときに知っている。
